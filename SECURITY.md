# Security policy

## Reporting a vulnerability

Please use a private
[GitHub security advisory](https://github.com/chrissotraidis/ringpad/security/advisories/new)
for vulnerabilities involving code execution, unsafe file import, path escape,
credentials or sensitive local data.

Do not open a public issue containing an exploit, game data, generated game
code, private filesystem paths, certificates, provisioning profiles or secrets.

Ordinary build, rendering, input or gameplay defects without security impact
can be filed through GitHub Issues.

## Supported version

RingPad is an experimental source preview. Security fixes target the latest
commit on `main`; no older release line is maintained.
