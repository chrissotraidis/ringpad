# Archived: Katana/SARecomp route (5-10 October 2026)

The original plan depended on SARecomp's private KatanaRecomp toolchain and
1,657 missing source files, then on a hand-built recovery core. Neither reached
a title screen. On 10 October Chris redirected the project to an independent
static recompilation; see [docs/prd.md](../../docs/prd.md).

This directory preserves that history: the original PRD and loops, status and
journal logs, recovery tests and patches, and the source-audit scripts. Many
files reference ignored local paths that no longer exist, so they are not
expected to build or run. Nothing here is a current instruction.
