# SonicPad 0.1.0 experimental preview

Sonic Adventure for iPhone and iPad, built from your own Dreamcast PAL v1.003
disc. SonicPad translates the game's SH-4 code ahead of time into C++, compiles
it for ARM64, and uses Flycast for Dreamcast hardware support. iOS renders
through Vulkan and MoltenVK. No JIT is used; code outside the generated set
runs through the interpreter fallback.

## Build and install

You need an Apple Silicon Mac, full Xcode with the iOS platform, CMake 3.24 or
newer, at least 6 GB of free build space, and your own supported GDI with its
three tracks. The app targets iOS/iPadOS 16 or later; older devices and the
minimum OS version have not received physical acceptance testing.

Follow the [installation guide](../INSTALL.md) to build a personal unsigned
IPA, sign it with your own sideloading tool and import the same game in the app.
Only **PAL v1.003 / MK-5100050** is supported. CDI, CHD, other revisions and the
PC/DX release are not supported.

The release attachments are the PadMint build recipe and its SHA-256 checksum.
There is no prebuilt app, disc image, translated game code or save file to
download. SonicPad's recipe works with a local checkout; inclusion in PadMint's
catalog is a separate step.

## Included

- Editable DCPad touch controls, physical-controller input and face-button mapping.
- A persistent ••• menu with save states, graphics, sound and control settings.
- Dreamcast Original graphics by default: 480p rendering and original textures.
- Optional higher resolution, xBRZ texture upscaling and iPhone widescreen.
- Hash-checked game import, VMU save import/export and diagnostic-log sharing.
- Max Rings, Infinite Lives and Unlock All Characters cheats for the supported disc.
- Ahead-of-time coverage from traced routes and static discovery across the
  game's executable modules.

## Preview limits

Prior M2 iPad Pro checks covered boot, title/attract sequences and selected
scripted gameplay routes. They do not establish a complete game play-through,
all characters or stages, iPhone hardware performance, extended audio/thermal
behavior or broad controller acceptance. Dreamcast Original's effect on the
reported control/visual feel still needs hands-on confirmation.

Install updates over the existing app with the same signing setup and export
your VMU save before changing installation methods. Removing the app removes
its local data. Save states are build-dependent; keep normal in-game saves too.
