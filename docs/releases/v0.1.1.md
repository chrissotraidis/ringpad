# RingPad 0.1.1

A polish release for the 0.1.0 preview. Build it the same way: choose RingPad
in [PadMint](https://github.com/chrissotraidis/padmint) 0.6.7 or newer, or run
`scripts/build-personal.py` (see the [installation guide](../INSTALL.md)).
Install it over 0.1.0 with the same signing setup to keep your disc, saves and
settings.

## Changes

- **One set of touch controls at launch.** Flycast's own touch gamepad no
  longer shows over RingPad's controls for the first second while the game
  boots.
- **New iPad layout.** New installs, and **••• → Controls → Move Controls →
  Reset**, use a layout tuned on a 12.9-inch iPad Pro: L and R side by side
  above a slightly smaller face diamond, with Start above them. It keeps its
  shape on every iPad size. A layout you already arranged is kept. Phones are
  unchanged.
- **External displays.** Only RingPad's own scene gets the game, so a
  connected display keeps the system's mirroring or extended display, as in the
  other Pad ports.
- **PadMint library.** RingPad answers to `padmint-ringpad://`, so PadMint's
  iPhone/iPad library shows it as installed even when you built it by hand.

## Limits

The preview limits from [0.1.0](v0.1.0.md) still apply. The external-display
change has not been tried with a physical TV or monitor. See
[known issues](../KNOWN-ISSUES.md) and the [validation record](../STATUS.md).

RingPad is unofficial and not affiliated with or endorsed by SEGA. The release
attachments are the PadMint build recipe and its SHA-256 checksum; there is no
prebuilt app, disc image, translated game code or save file to download.
